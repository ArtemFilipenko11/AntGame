## Архитектура инициализации

Awake используется для локальной подготовки объектов.

GameplayContext использует Start как единственную
точку запуска игровой инициализации.

GameplaySystem.Initialize() вызывается после загрузки
сцены и подготовки всех её объектов.

Игровая логика не зависит от порядка Awake/Start между
отдельными GameObject.

## Боевая система

`IDamageable` определяет контракт получения урона. `CombatComponent` передаёт урон через этот интерфейс и не зависит от `HealthComponent`. Объекты сами определяют реакцию на урон, реализуя `IDamageable`.

`HealthComponent` — базовая реализация здоровья: хранит текущее и максимальное здоровье, обрабатывает урон и лечение, сообщает об изменении здоровья и смерти. Он не привязан к конкретному персонажу.

Поиск целей, дистанция атаки, перезарядка, анимации и интеграция с AI в базовую реализацию не входят.
